# Amapati.com — Simplified Shopping & Technology Marketplace

> Clean, ultra-fast, mobile-first B2B & B2C technology marketplace inspired by Alibaba. Built with **React 19, TypeScript, Tailwind CSS, and Supabase**.

---

## 🌟 Key Features

1. **Role-Based Access Control (RBAC)**:
   - **Superuser (`stopollos@gmail.com`)**: Created automatically on first setup with full system governance. Can invite editors, suspend/activate/revoke roles, view chronological audit logs, and customize global marketplace settings.
   - **Editor (Max 20 Active)**: Can create/edit products, manage categories & homepage hero banners, update order statuses, and reply to buyer inquiries & RFQs. Enforced strictly at both database trigger and application level.
   - **Customer**: Sourcing RFQs, tiered wholesale pricing discounts, multi-currency display, 3-step checkout (Pay on Delivery, Mobile Money, Card Escrow), order tracking, and inquiry history.

2. **Editor Invitation & Access Request Flow**:
   - Single-use invite links generated by the Superuser expiring in 48 hours.
   - Public "Request Editor Access" form for new catalog curators, routed directly to the Superuser's review queue.
   - Hard cap of 20 active editors strictly enforced.

3. **High-Fidelity Storefront**:
   - Tiered pricing engine: unit price automatically adapts based on ordered quantity (e.g., 1–9, 10–49, 50–199, 200+).
   - Live currency converter: USD ($), EUR (€), GBP (£), KES (KSh), NGN (₦), CNY (¥).
   - "Request a Quote (RFQ)" instant modal for custom enterprise sourcing.
   - Verified supplier badges, Trade Assurance, technical specifications table, and customer reviews.
   - Complete 3-step mobile-first checkout flow with order tracking.
   - High-contrast Dark Mode with persistent theme switching.

## 🚀 Quick Start (Development)

```bash
# 1. Clone repository
git clone https://github.com/amapati/amapati-marketplace.git
cd amapati-marketplace

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open `http://localhost:3000` to preview the app.

## 🗄️ Supabase Backend Setup & Database Migrations

1. Create a project at [supabase.com](https://supabase.com).
2. Go to your **SQL Editor** in the Supabase Dashboard.
3. Open `supabase/migrations/20240101000000_init_amapati.sql` in this repo (or open the **Supabase Schema** tab in the Amapati Admin panel).
4. Paste and execute the script. It provisions:
   - Tables: `profiles`, `invites`, `editor_requests`, `categories`, `products`, `product_images`, `price_tiers`, `orders`, `order_items`, `cart_items`, `favorites`, `inquiries`, `reviews`, `banners`, `audit_log`, `settings`.
   - Enums & Functions.
   - Row Level Security (RLS) policies.
   - The PostgreSQL trigger `trg_enforce_editor_limit` enforcing the **maximum 20 active editors** limit.
   - Trigger `on_auth_user_created` automatically assigning `superuser` role to `stopollos@gmail.com`.

### Seeding the Superuser:
When `stopollos@gmail.com` signs up via Supabase Auth (Email/Password or Google OAuth), the database trigger automatically grants the `superuser` role with complete administrative privileges.

## 🌐 Deployment to Vercel or Netlify

### Deploying to Vercel
1. Push your repository to GitHub.
2. In Vercel, click **New Project** and select the repository.
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Set Environment Variables:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```
6. Click **Deploy**.

### Deploying to Netlify
1. Connect repository in Netlify.
2. Build command: `npm run build`
3. Publish directory: `dist`
4. Add environment variables in Site configuration > Environment variables.
5. Create a `_redirects` file in `public/` containing: `/* /index.html 200` to support single-page routing.
